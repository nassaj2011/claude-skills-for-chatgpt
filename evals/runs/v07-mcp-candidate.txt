Both contracts reject unknown fields, enforce bounded field lengths and timeouts, and derive actor identity and tenant from authenticated server-side context—not model-provided input. Reservation details should be minimized; do not return customer PII unless separately justified and authorized.

### Permission matrix

| Operation | Caller/scope | Consent | Enforcement |
|---|---|---|---|
| `venue.list_reservations` | Authenticated actor with `reservations:read` for the resolved tenant and `venue_id` | Normal access authorization | Verify tenant ownership/membership before query; paginate and redact fields |
| `venue.change_slot_state` | Authenticated actor with `slots:write` for the resolved tenant and venue | Explicit, action-bound confirmation | Re-check authorization at write time; validate legal state transition; persist idempotency record and audit event |
| Cross-tenant/unknown venue | Any | N/A | Deny without revealing whether the venue exists |
| Elevated override | Designated operator role only | Separate documented approval | Require policy-backed elevation and auditable reason; never infer from tool description |

### Error taxonomy and retry rules

| Code | Meaning | Retry guidance |
|---|---|---|
| `INVALID_INPUT` | Malformed value, excessive length, invalid cursor/state | Fix input; no retry |
| `UNKNOWN_FIELD` | Request contains an unsupported property | Remove field; no retry |
| `UNAUTHENTICATED` | No valid actor/session | Re-authenticate |
| `FORBIDDEN` | Actor lacks tenant, venue, or action permission | Do not retry |
| `CONFIRMATION_REQUIRED` | Write lacks matching explicit confirmation | Obtain new confirmation |
| `INVALID_STATE_TRANSITION` | Requested state change violates business rules | Review current state; no automatic retry |
| `IDEMPOTENCY_CONFLICT` | Same key used with different request body | Use a new key only after resolving intent |
| `REPLAYED_RESULT` | Same key and equivalent prior request | Return original result; no new write |
| `RATE_LIMITED` | Vendor/service quota exceeded | Retry only after bounded `retry_after` |
| `DEPENDENCY_TIMEOUT` | Outcome may be unknown | Reconcile using idempotency key; do not blindly repeat |
| `INTERNAL_ERROR` | Unexpected server failure | Return redacted correlation ID; investigate |
