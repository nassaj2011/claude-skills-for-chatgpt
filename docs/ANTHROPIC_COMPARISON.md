# Anthropic Skills mapping and attribution

This is a **conceptual mapping**, not a file-by-file port. **No original Anthropic skill text, scripts, images or assets are copied into this repository.**

| Anthropic public example | New independent skill(s) here | Difference / scope |
| --- | --- | --- |
| [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) | frontend-design-direction | Product-specific visual direction, accessibility and verification |
| [web-artifacts-builder](https://github.com/anthropics/skills/tree/main/skills/web-artifacts-builder) | react-artifacts-builder | Component state, typed API integration, reproducible tests |
| [theme-factory](https://github.com/anthropics/skills/tree/main/skills/theme-factory) | theme-design-system | Design tokens, interaction states, RTL and contrast |
| [canvas-design](https://github.com/anthropics/skills/tree/main/skills/canvas-design) | visual-assets-design | Asset production briefs and rights-aware QA; not a PDF/image engine |
| [mcp-builder](https://github.com/anthropics/skills/tree/main/skills/mcp-builder) | mcp-integration-builder | Contracts, least privilege, safe retries and tool boundary security |
| [claude-api](https://github.com/anthropics/skills/tree/main/skills/claude-api) | llm-api-integration | Provider-neutral OpenAI/Anthropic integration guidance |
| [webapp-testing](https://github.com/anthropics/skills/tree/main/skills/webapp-testing) | playwright-webapp-testing | Host-neutral testing process; depends on actual Playwright installation |
| [skill-creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator) | skill-authoring-toolkit | Agent Skills authoring and testing approach |

Additional original skills close gaps common to end-to-end delivery: backend debugging, persistent-state invariants, security, CI/CD, incident response, release gates and product requirements.
